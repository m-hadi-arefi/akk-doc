# Arian Khodro Technical Glossary

| Term | Definition |
|---|---|
| **ACL** | Anti-Corruption Layer — an adapter isolating modern applications from legacy system complexity. |
| **ADR** | Architecture Decision Record — formal immutable record capturing an architectural decision. |
| **ARB** | Architecture Review Board — governing body approving enterprise technical decisions. |
| **BABOK** | Business Analysis Body of Knowledge — standard for business analysis practices. |
| **BPMN** | Business Process Model and Notation — graphical specification for workflow modeling. |
| **CDC** | Change Data Capture — tracking and streaming database changes in real-time. |
| **Core Platform** | Shared enterprise capabilities layer providing identity, APIs, and events (not an ERP). |
| **CQRS** | Command Query Responsibility Segregation — separating read and write models. |
| **MDM** | Master Data Management — authoritative single source of truth for core business entities. |
| **Saga** | Design pattern coordinating distributed transactions via compensation actions. |
| **Strangler Fig** | Migration pattern incrementally replacing legacy components with new services. |
| **Tadark** | Arian Khodro's legacy accounting and parts inventory application (Delphi 32-bit). |
| **TOGAF** | The Open Group Architecture Framework — enterprise architecture standard. |
| **VIN** | Vehicle Identification Number — unique 17-character automotive identifier. |
