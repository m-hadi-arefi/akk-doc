# Extreme Programming (XP) Blueprint

## What It Is
An agile methodology focused on rigorous engineering discipline and code quality.

## Core Engineering Practices
- Test-Driven Development (TDD): Write failing test before writing code.
- Pair Programming: Two engineers sharing one workstation.
- Continuous Integration: Merging and building multiple times per day.
- Refactoring: Continual simplification of code without changing external behavior.
- Collective Code Ownership: Any engineer can improve any part of the codebase.

## When to Use
- Complex financial calculations, accounting ledger engines, and core security modules.
