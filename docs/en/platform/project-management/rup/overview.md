# Rational Unified Process (RUP) Blueprint

## What It Is
An iterative, architecture-centric software engineering process divided into four sequential phases: **Inception**, **Elaboration**, **Construction**, and **Transition**.

## Phase Structure
- **Inception**: Scope definition, business case, initial feasibility.
- **Elaboration**: Addressing architectural risks, establishing the baseline architecture.
- **Construction**: Iteratively building capabilities upon the stable architecture.
- **Transition**: User testing, deployment, legacy migration cutover.

## When to Use
- Large enterprise core platform modernizations where architectural failure would be catastrophic.
