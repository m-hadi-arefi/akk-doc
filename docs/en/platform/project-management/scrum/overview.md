# Scrum Methodology Blueprint

## What It Is
An agile framework structured around fixed-length iterations called **Sprints** (typically 2 weeks), delivering a potentially shippable Increment of software each cycle.

## Core Elements
- **Roles**: Product Owner (PO), Scrum Master (SM), Developers.
- **Ceremonies**: Sprint Planning, Daily Scrum (15 min), Sprint Review, Sprint Retrospective.
- **Artifacts**: Product Backlog, Sprint Backlog, Increment, Definition of Done (DoD).

## When to Use
- Development of customer-facing products and internal operational applications with active stakeholder feedback.

## When NOT to Use
- Pure operational maintenance streams with random urgent interruptions (use [Kanban](../kanban/overview.md)).
