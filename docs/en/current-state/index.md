# Current State Documents & Operational Inventory

## Executive Overview
This repository section is dedicated to recording, organizing, and maintaining all **Current State Documentation** for Arian Khodro. While the [Initial Review Documents](/en/initial-review/) encompass the strategic transformation architecture and roadmap, this space serves as the living repository for operational manuals, current process workflows, existing software inventories, spreadsheet registries, and department SOPs.
