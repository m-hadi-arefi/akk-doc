## Roadmap Revision Triggers

The roadmap must be revisited when:

- Discovery reveals new systems or integrations.
- Team size changes.
- Budget constraints change.
- Business priorities shift.
- A Phase deliverable shows significant deviation from plan.
- A major architectural decision is changed via ADR.

## Minimum Viable Roadmap

If resources are constrained, the minimum viable roadmap might be:

1. **Discovery** (1-2 months): Complete system inventory, data mapping, stakeholder interviews.
2. **Core Platform MVP** (3-4 months): Identity, authentication, API gateway, audit logging.
3. **Tadark Adapter** (2-3 months): Build the adapter, begin wrapping Tadark.
4. **First capability migration** (2-3 months): Migrate one capability to validate the approach.
