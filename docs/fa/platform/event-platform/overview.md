# مشخصات پلتفرم رویدادها (Event Platform)

## مسئله
یکپارچه‌سازی‌های مستقیم و نقطه به نقطه (Point-to-Point HTTP) میان سیستم‌ها موجب وابستگی شدید زمانی می‌شد؛ به طوری که کندی یا قطعی یک سیستم، موجی از خرابی‌های زنجیره‌ای را در کل سازمان پدید می‌آورد.

## هدف
ارائه یک ستون فقرات ناهمگام، مقیاس‌پذیر و خطاپذیر برای تبادل رویدادها بر پایه معماری رویدادمحور (Event-Driven Architecture) در آریان خودرو.

## مسئولیت‌ها
- استریم توزیع‌شده پیام‌ها با توان عملیاتی بسیار بالا (Apache Kafka).
- رجیستری ساختار داده‌ها (Schema Registry) برای تضمین سازگاری به عقب قراردادهای JSON Schema یا Protobuf.
- مدیریت صف نامه‌های مرده (Dead Letter Queue - DLQ) برای پیام‌های پردازش‌نشده.
- راهبری سرفصل‌ها (Topics)، راهبردهای پارتیشن‌بندی و پایش موقعیت پردازش مصرف‌کنندگان.

## عدم مسئولیت‌ها
- ارائه پاسخ فوری و مسدودکننده (ماهیت سیستم کاملاً ناهمگام است).
- جایگزینی با پایگاه‌های داده رابطه‌ای برای پرس‌وجوهای پیچیده تراکنشی.

## مهم‌ترین سرفصل‌های رویداد سازمانی (Core Topics)
- `arian.vehicle.lifecycle` (ثبت پلاک، تخصیص عاملیت، تحویل مشتری، سرویس دوره‌ای)
- `arian.customer.lifecycle` (ایجاد مشتری، به‌روزرسانی مشخصات، اعتبارسنجی)
- `arian.workshop.repairs` (گشایش دستور کار، درخواست قطعه، پایان تعمیرات، صدور فاکتور)
- `arian.accounting.journal` (ثبت سند مالی، درخواست تطبیق حساب)
