# مشخصات سرویس لاگ بازرسی (Audit Service)

## مسئله
انطباق با الزامات قانونی، ممیزی‌های مالی و ردیابی‌های امنیتی نیازمند ثبت تغییرناپذیر اقدامات حساس کاربران است؛ امری که سیستم‌های سنتی یا اصلاً ثبت نمی‌کردند یا در جدول‌های معمولی و قابل دستکاری SQL ذخیره می‌نمودند.

## هدف
ایجاد یک ردپای حسابرسی متمرکز، ضدجعل و الحاقی (Append-Only) برای ثبت تمامی تراکنش‌های حساس و رویدادهای امنیتی در سراسر آریان خودرو.

## مسئولیت‌ها
- دریافت رویدادهای بازرسی ساختاریافته از طریق سرفصل‌های ناهمگام Kafka.
- ذخیره‌سازی قطعی و تغییرناپذیر وقایع (ذخیره‌سازی یک‌بارنوشتن WORM / لاگ‌های فقط الحاقی).
- ارائه قابلیت جستجو و استعلام به مدیران ذی‌صلاح امنیت و بازرسی سازمان.
- اعمال سیاست‌های دوره ماندگاری داده‌ها (مانند نگهداری الزامی ۷ ساله برای اسناد مالکیت و تراکنش‌های مالی).
