# مشخصات سکوی یکپارچه‌سازی و آداپتورها

## مسئله
سیستم‌های موروثی نظیر تدارک فاقد APIهای مدرن REST یا gRPC بوده و به کدهای ۳۲ بیتی دلفی، دستکاری مستقیم جداول پایگاه داده، یا تبادل فایل‌های CSV متکی هستند.

## هدف
ایجاد سرویس‌های آداپتور اختصاصی، لایه‌های ضدفساد (Anti-Corruption Layer - ACL) و پروکسی‌های الگوی شاخه خفه‌کننده برای اتصال ایمن سیستم‌های موروثی به سکوی مرکزی نوین بدون انتقال بدهی‌های فنی گذشته به ساختار جدید.

## استراتژی‌ها و آداپتورهای یکپارچه‌سازی

### ۱. آداپتور مدرن‌سازی تدارک (Tadark ACL Adapter)
- یک میکروسرویس واسط اختصاصی که تراکنش‌های خواندن و نوشتن تدارک را از طریق رویه‌های ذخیره‌شده کنترل‌شده (Stored Procedures) انجام داده و آنها را به رویدادهای استاندارد کافکا و APIهای REST ترجمه می‌کند.
- **قانون قطعی**: هیچ برنامه جدیدی حق اتصال مستقیم به دیتابیس تدارک را ندارد؛ کلیه تعاملات باید صرفاً از طریق این آداپتور انجام شود.

### ۲. آداپتورهای پرداخت و درگاه‌های بانکی
- پل استاندارد پرداخت برای انتزاع پروتکل‌های درگاه‌های بانکی و شاپرک با تطبیق خودکار اسناد مالی و تضمین کلیدهای یکتایی تراکنش (Idempotency).

### ۳. آداپتورهای پیامک و ارتباط با مشتریان
- سرویس توزیع اعلان‌های سازمانی با قابلیت سوییچ خودکار میان ارائه‌دهندگان پیامکی در صورت اختلال در یک سرویس‌دهنده.
