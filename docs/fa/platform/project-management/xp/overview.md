# چارچوب برنامه‌نویسی مفرط (Extreme Programming - XP)

## چیستی
یک متدولوژی چابک که بالاترین اولویت را به انضباط‌های سخت‌گیرانه مهندسی و ارتقای مداوم کیفیت سورس‌کد اختصاص می‌دهد.

## شیوه‌های کلیدی مهندسی
- **توسعه آزمون‌محور (TDD)**: نوشتن تست ناموفق قبل از نوشتن کد اصلی برنامه.
- **برنامه‌نویسی دونفره (Pair Programming)**: اشتراک یک ایستگاه کاری توسط دو مهندس به صورت هم‌زمان.
- **یکپارچه‌سازی مداوم (Continuous Integration)**: ادغام و تست خودکار کدها چندین بار در طول روز.
- **بازآفرینی مداوم (Refactoring)**: ساده‌سازی پیوسته ساختار کد بدون تغییر رفتار خروجی.
- **مالکیت جمعی کد (Collective Ownership)**: حق هر مهندس برای بهبود هر بخش از سورس‌کد.

## زمان کاربرد
- الگوریتم‌های حساس مالی، موتورهای تسویه حسابداری، و ماژول‌های حیاتی رمزنگاری و امنیت.
