# مرکز متدولوژی‌های مدیریت و تحویل پروژه

این مرکز راهنماها و الگوهای عینی و کاربردی را برای انتخاب و به‌کارگیری متدولوژی‌های تحویل نرم‌افزار در پروژه‌های مختلف شرکت آریان خودرو ارائه می‌دهد.

## فهرست متدولوژی‌ها
- [راهنمای انتخاب متدولوژی](./methodology-selection/overview.md) — ماتریس تصمیم‌گیری برای انتخاب متد مناسب بر اساس ویژگی‌های پروژه.
- [اسکرام (Scrum)](./scrum/overview.md) — چارچوب تکرارشونده و مبتنی بر اسپرینت برای تیم‌های توسعه محصول.
- [کانبان (Kanban)](./kanban/overview.md) — مدیریت جریان مستمر کار و محدودسازی کار در جریان (WIP) برای تیم‌های عملیات و سکو.
- [فرایند یکپارچه رشنال (RUP)](./rup/overview.md) — متدولوژی معماری‌محور و فازبندی‌شده برای سیستم‌های پیچیده و پرریسک.
- [برنامه‌نویسی مفرط (XP)](./xp/overview.md) — شیوه‌های انضباطی مهندسی برای ارتقای حداکثری کیفیت کد.
- [آبشاری و سنتی (Waterfall)](./waterfall/overview.md) — تحویل مبتنی بر مایلستون‌های خطی برای قراردادهای پیمانکاری با محدوده کاملاً ثابت.
- [حاکمیت پروژه PRINCE2](./prince2/overview.md) — حاکمیت ساختاریافته پروژه با هیئت‌مدیره پروژه و توجیه مداوم تجاری.
- [پیکره دانش مدیریت پروژه (PMI PMBOK)](./pmi/overview.md) — حوزه‌های ده‌گانه دانش و گروه‌های فرآیندی مدیریت پروژه‌های بزرگ سازمانی.
- [اصول و ذهنیت چابک (Agile)](./agile/overview.md) — ارزش‌های بنیادین چابکی و فرهنگ مهندسی مدرن.
