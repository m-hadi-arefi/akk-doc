# چارچوب حاکمیت پروژه PRINCE2

## چیستی
متدولوژی PRINCE2 یک روش فرآیندمحور برای مدیریت اثربخش پروژه‌ها است که بر توجیه مداوم کسب‌وکاری و ساختار سازمانی مشخص پروژه تأکید دارد.

## ارکان کلیدی
- **۷ اصل**: توجیه مداوم کسب‌وکار، یادگیری از تجربیات، نقش‌های تعریف‌شده، مدیریت مرحله‌ای، مدیریت بر اساس استثنا، تمرکز بر محصولات خروجی، تطبیق با محیط پروژه.
- **هیئت‌مدیره پروژه (Project Board)**: مدیر ارشد اجرایی (کسب‌وکار)، کاربر ارشد (عملیات)، تأمین‌کننده ارشد (فنی).

## زمان کاربرد
- لایه حاکمیت عالی و راهبری کلان پروژه‌های چندپیمانکاره و برنامه‌های تحول دیجیتال در سطح هلدینگ.
