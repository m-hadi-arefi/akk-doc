# چارچوب مدیریت پروژه PMI PMBOK

## چیستی
استاندارد مؤسسه مدیریت پروژه (PMI) که شامل ۵ گروه فرآیندی (آغازین، برنامه‌ریزی، اجرا، پایش و کنترل، اختتام) و ۱۰ حوزه دانش تخصصی است.

## ۱۰ حوزه دانش
مدیریت یکپارچگی، محدوده، زمان‌بندی، هزینه، کیفیت، منابع انسانی، ارتباطات، ریسک، تدارکات و مدیریت ذی‌نفعان.

## زمان کاربرد
- مدیریت پورتفولیوی پروژه‌های کلان، بودجه‌بندی سازمانی و هماهنگی دفتر مدیریت پروژه (PMO).
