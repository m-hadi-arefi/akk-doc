# چارچوب مدل خطی آبشاری (Predictive Waterfall)

## چیستی
یک مدل توسعه خطی و مرحله‌ای که در آن هر فاز پیش از آغاز فاز بعدی باید تأییدیه رسمی دریافت کند: نیازمندی‌ها -> طراحی معماری -> پیاده‌سازی کد -> تست و اعتبارسنجی -> نگهداری.

## زمان کاربرد
- قراردادهای برون‌سپاری با مبالغ کاملاً ثابت و تحویل اقلام مشخص قانونی و حقوقی.
- پروژه‌های زیرساخت سخت‌افزاری مرکز داده، کابل‌کشی و استقرار فیزیکی شبکه.

## زمان عدم کاربرد
- توسعه برنامه‌های مدرن و سفارشی کسب‌وکار که در آنها نیازمندی‌ها همگام با استفاده عملیاتی تکامل می‌یابند.
