# مدیریت APIها و گذرگاه یکپارچگی

درگاه API و گذرگاه پیام سکوی مرکزی نقش شریان اصلی ارتباطی بین نرم‌افزارهای سازمان، وب‌سرویس‌های بانکی، سامانه‌های دولتی (مانند گمرک و مالیات) و پورتال مشتریان را ایفا می‌کند.

---

## ۱. وظایف کلیدی درگاه API (API Gateway)

1. **مدیریت نرخ درخواست (Rate Limiting & Throttling)**:
   جلوگیری از بار اضافی روی سیستم‌های موروثی قدیمی (نظیر تادارک) هنگام ثبت‌نام‌های پرترافیک خودرو.
2. **بررسی امنیت و انقضای توکن‌ها**:
   اعتبارسنجی خودکار امضای دیجیتال توکن‌های JWT پیش از هدایت درخواست به سرویس‌های پسین (Backend Services).
3. **کش هوشمند پاسخ‌ها (Response Caching)**:
   پاسخ‌دهی سریع به استعلام‌های تکراری مانند کاتالوگ رنگ و مدل خودروها یا مشخصات نمایندگی‌های مجاز بدون درگیر کردن دیتابیس اصلی.

---

## ۲. گذرگاه رویدادها (Event-Driven Architecture)

به جای ارتباطات همگام (Synchronous HTTP) که در صورت قطعی یک سیستم کل فرآیند متوقف می‌شود، از صف پیام و الگوی انتشار/اشتراک (Pub/Sub) استفاده می‌گردد:

```text
[سامانه CRM] ──► (رویداد: ثبت‌نام قطعی خودرو) ──► [Event Bus]
                                                      │
                       ┌──────────────────────────────┼──────────────────────────────┐
                       ▼                              ▼                              ▼
             [تخصیص شاسی در انبار]         [ایجاد پیش‌فاکتور در مالی]     [ارسال پیامک تبریک به مشتری]
```
