# مفهوم سکوی مرکزی (Core Platform)

یکی از اشتباهات متداول در سازمان‌ها، اشتباه گرفتن **سکوی مرکزی (Core Platform)** با یک نرم‌افزار **ERP** است. این سند مرزهای معماری، فلسفه شکل‌گیری و سرویس‌های مشترک سکوی مرکزی آرین خودرو را تشریح می‌کند.

---

## ۱. تفاوت کلیدی Core Platform با ERP

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   لایه‌های تجاری و کاربردی (Applications)              │
│       [سامانه CRM]        [سیستم حسابداری تادارک]     [پورتال نمایندگی‌ها]   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ استاندارد JSON / REST APIs
┌───────────────────────────────────▼────────────────────────────────────┐
│                    سکوی مرکزی آرین خودرو (Core Platform)               │
│  ┌───────────────────────┐  ┌───────────────────────┐  ┌────────────┐  │
│  │ احراز هویت متمرکز     │  │ درگاه و مدیریت APIها   │  │ داده مرجع  │  │
│  │ (SSO & RBAC)          │  │ (API Gateway)         │  │ (MDM)      │  │
│  └───────────────────────┘  └───────────────────────┘  └────────────┘  │
│  ┌───────────────────────┐  ┌───────────────────────┐  ┌────────────┐  │
│  │ گذرگاه رویدادها       │  │ پایگاه حسابرسی و امنیت│  │ پایش‌پذیری │  │
│  │ (Event Bus / Kafka)   │  │ (Audit Trail)         │  │ (APM Logs) │  │
│  └───────────────────────┘  └───────────────────────┘  └────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

| مشخصه | سیستم ERP | سکوی مرکزی (Core Platform) |
| :--- | :--- | :--- |
| **تعریف** | یک نرم‌افزار تجاری یکپارچه برای فرآیندهای مالی، انبار و منابع انسانی | یک بستر زیرساختی و اشتراکی نرم‌افزاری برای اتصال کلیه برنامه‌ها |
| **وابستگی به فرآیند** | سازمان باید فرآیندهای خود را با روال‌های بسته ERP تطبیق دهد | بدون تحمیل منطق بسته؛ سرویس‌های استاندارد هویت، داده و اتصال ارائه می‌دهد |
| **انعطاف در تغییر** | تعویض یا ارتقای ERP بسیار پرهزینه و طولانی (چندین سال) است | ماژولار است؛ بدون وابستگی می‌توان سیستم مالی یا CRM را در لایه بالا تغییر داد |

---

## ۲. چهار ستون اصلی سکوی مرکزی آرین خودرو

1. **[احراز هویت و سطوح دسترسی (Identity & RBAC)](/fa/platform/core-platform/identity-access)**: ورود یکپارچه برای تمام سامانه‌ها، حذف نام کاربری و پسوردهای پراکنده.
2. **[درگاه مدیریت API و یکپارچگی](/fa/platform/core-platform/api-gateway)**: کانال ایمن و مانیتورشده برای تبادل اطلاعات بین تادارک، CRM و پورتال‌های استانی.
3. **[مدیریت داده‌های مرجع (Master Data Management)](/fa/platform/core-platform/master-data)**: ایجاد یک مرجع واحد و قطعی برای اطلاعات خودروها، مشتریان و کدهای فنی قطعات یدکی.
4. **رهگیری و لاگ بازرسی (Audit & Observability)**: ثبت تغییرناپذیر کلیه تراکنش‌های حساس، ورود کاربران و دسترسی‌های داده‌ای.
