# ستون سکوی مرکزی (Core Platform)

**سکوی مرکزی (Core Platform)** قابلیت‌های فنی و سازمانی مشترک، استاندارد و با قابلیت استفاده مجدد را در اختیار تمامی نرم‌افزارهای دیجیتال شرکت آریان خودرو قرار می‌دهد.

## اصل راهنما: سکوی مرکزی با ERP برابر نیست (Core Platform ≠ ERP)

```text
┌─────────────────────────────────────────────────────────────┐
│                 نرم‌افزارهای تجاری و کاربردی                 │
│  (فروش خودرو، عملیات تعمیرگاهی، قطعات یدکی، ارتباط با مشتری) │
└──────────────────────────────┬──────────────────────────────┘
                               │ مصرف قابلیت‌های مشترک
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                         سکوی مرکزی                          │
│   احراز هویت • کنترل دسترسی • API • رویدادها • داده‌های مرجع │
└──────────────────────────────┬──────────────────────────────┘
                               │ اتصال از طریق آداپتورها
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 سامانه‌های موروثی و خارجی                    │
│            (سیستم حسابداری تدارک، بانک‌ها، پیامک)           │
└──────────────────────────────┴──────────────────────────────┘
```

- **سکوی مرکزی یک سیستم ERP نیست**: این سکو منطق اختصاصی فروش خودرو، محاسبه پورسانت عاملیت‌ها، یا فرایندهای خاص پذیرش تعمیرگاه را در بر نمی‌گیرد.
- **مسئولیت‌ها**: ارائه قابلیت‌های فرافرایندی و متقاطع (احراز هویت، کنترل مجوزها، درگاه API، گذرگاه رویدادها، مدیریت داده‌های مرجع MDM، لاگ بازرسی، پایش‌پذیری).
- **عدم مسئولیت‌ها**: منطق تجاری خاص دامنه‌ها، لایه‌های رابط کاربری برنامه‌ها، پردازش تراکنش‌های تخصصی هر نرم‌افزار.

## فهرست قابلیت‌های سکوی مرکزی
- [مرور کلی معماری سکو](./overview.md) — چشم‌انداز معماری، اصول طراحی و نقشه راه توسعه.
- [سرویس احراز هویت (Identity)](../identity/overview.md) — ورود یکپارچه (SSO)، استانداردهای OIDC/OAuth 2.0 و ورود دومرحله‌ای (MFA).
- [سرویس کنترل دسترسی (Authorization)](../authorization/overview.md) — ارزیابی متمرکز مجوزها با مدل‌های RBAC و ABAC.
- [مدیریت و درگاه API](../api-management/overview.md) — درگاه یکپارچه سازمانی، هدایت ترافیک، محدودسازی نرخ فراخوانی (Rate Limiting).
- [پلتفرم رویدادها (Event Platform)](../event-platform/overview.md) — کارگزار پیام سازمانی، مدیریت سرفصل‌ها (Topics) و الگوی انتشار/اشتراک (Pub/Sub).
- [مدیریت داده‌های مرجع (MDM)](../master-data/overview.md) — ثبت سوابق طلایی (Golden Records) برای خودرو، مشتری و تأمین‌کننده.
- [سرویس لاگ بازرسی (Audit)](../audit/overview.md) — ثبت تغییرناپذیر و ضدجعل تمامی وقایع و تراکنش‌های حساس سازمان.
- [سکوی داده (Data Platform)](../data-platform/overview.md) — استخراج بلادرنگ داده‌ها (CDC)، دریاچه داده (Lakehouse) و گزارش‌گیری تحلیلی.
- [سکوی یکپارچه‌سازی و آداپتورها](../integration/overview.md) — آداپتورهای سازمانی، لایه‌های ضدفساد (ACL) و الگوی مهاجرت تدریجی.
- [سکوی پایش‌پذیری (Observability)](../observability/overview.md) — جمع‌آوری لاگ‌های متمرکز، ردگیری توزیع‌شده (Distributed Tracing) و APM.
- [متدولوژی‌های تحویل پروژه](../project-management/) — ارزیابی، راهنما و گزینش چارچوب‌های مهندسی تحویل نرم‌افزار.
