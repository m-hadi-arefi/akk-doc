# مدیریت داده‌های مرجع (MDM)

داده‌های مرجع (Master Data)، اطلاعات پایه‌ای و مشترک سازمان هستند که باید در تمامی بخش‌ها یکسان و معتبر باشند. نبود سیستم متمرکز MDM در آرین خودرو، عامل اصلی ثبت داده‌های تکراری، اطلاعات تماس نادرست مشتریان و مغایرت شماره شاسی در پرونده‌های گارانتی بوده است.

---

## ۱. سه موجودیت اصلی داده مرجع در آرین خودرو

```text
┌───────────────────────────────┐ ┌───────────────────────────────┐ ┌───────────────────────────────┐
│     داده مرجع مشتریان         │ │      داده مرجع خودروها        │ │    داده مرجع قطعات یدکی       │
│ • شناسه ملی یکتا / کد فراگیر  │ │ • کد شناسایی خودرو (VIN)      │ │ • کد فنی قطعه (Part Number)   │
│ • شماره همراه معتبر (احرازنشده)│ │ • شماره موتور و رنگ رسمی     │ │ • انطباق با مدل‌های خودرو     │
│ • وضعیت حقوقی یا حقیقی       │ │ • تیپ، سال ساخت و مدل       │ │ • قیمت مصوب و موجودی مبنا     │
└───────────────────────────────┘ └───────────────────────────────┘ └───────────────────────────────┘
```

## ۲. قوانین طلایی پاکسازی و حاکمیت داده‌ها

1. **قانون مرجعیت شماره شاسی (Golden VIN Record)**:
   کد VIN خودرو ۱۷ رقمی استاندارد است. این شناسه به محض ورود خودرو در گمرک ثبت شده و هیچ سیستمی اجازه تغییر یا ثبت دستی مجدد آن را بدون تایید مدیر بازرگانی نخواهد داشت.
2. **یکتایی مشتری بر پایه کد ملی**:
   تمامی سامانه‌ها موظفند سوابق مشتری را به کد ملی استعلام‌شده متصل نمایند؛ ایجاد رکوردهای تکراری برای یک فرد با املای متفاوت نام مسدود می‌شود.
3. **تغییر قیمت قطعات فقط در سرویس مرجع**:
   قیمت روز قطعات یدکی و لوازم مصرفی تنها در سرویس MDM به‌روزرسانی شده و سایر سامانه‌ها (CRM، تعمیرگاه‌ها و تادارک) ملزم به همگام‌سازی از این مبدأ هستند.
