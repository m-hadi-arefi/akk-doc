# سیاهه یکپارچه‌سازی‌های فعلی

مستندات اختصاصی هر یک از اتصالات سامانه‌ها، پروتکل‌های مورد استفاده و فرکانس تبادل اطلاعات در این بخش مستند می‌شود.

## یکپارچه‌سازی‌های شناخته‌شده فعلی
- **اتصالات سامانه تدارک**: در حال حاضر اطلاعات به صورت دسته‌ای و با استفاده از خروجی‌های سنتی یا ارتباطات مستقیم پایگاه داده انجام می‌شود.

## یکپارچه‌سازی‌های در حال کشف
کلیه اتصالات غیررسمی، جریان‌های تبادل فایل اکسل و اسکریپت‌های انتقال داده میان انبارها، عاملیت‌ها و ستاد در طول مصاحبه‌های شناخت کشف و به این مستند افزوده خواهند شد.
