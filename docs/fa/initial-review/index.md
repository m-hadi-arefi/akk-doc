# داکیومنت‌های بررسی اولیه (Initial Review Documents)

## معرفی پوشه بررسی اولیه
این پوشه شامل مجموعه کامل مستندات فنی، معماری و راهبردی تولید شده در فاز **بررسی اولیه تحول سازمانی آرین خودرو** است. این مستندات نقشه راه جامع، مهندسی معکوس سیستم‌های قدیمی، طراحی پلتفرم نرم‌افزاری مدرن، پروژه‌های عملیاتی هوش مصنوعی و مدل حاکمیت سازمان را پوشش می‌دهند.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        پوشه مستندات بررسی اولیه (INITIAL REVIEW)                       │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  ۰۰. سند راهبردی مدیران ارشد  ◄ یادداشت مدیرعامل، منشور اختیارات، سنجه‌های کلان        │
│  ۰۱. شناخت میدانی و واقعیت‌ها  ◄ تحلیل فرآیندهای جاری، تحلیل فنی تدارک، رجیستری دردها │
│  ۰۲. استراتژی جامع تحول       ◄ ارکان سه‌گانه، ساخت یا خرید، مدل عملیاتی هدف           │
│  ۰۳. معماری نرم‌افزار و داده  ◄ مونولیت ماژولار، لایه ضدفساد، رکورد طلایی شاسی (VIN)   │
│  ۰۴. تحول عمل‌گرایانه هوش‌مصنوعی◄ OCR اسناد گمرکی، بازرسی بدنه، حاکمیت و اخلاق AI       │
│  ۰۵. اجرا، تحویل چابک و تغییر ◄ اسپرینت‌های ۲ هفته‌ای، ۳ پایلوت ۹۰ روزه، مدل ADKAR    │
│  ۰۶. حاکمیت سازمانی و سنجه‌ها ◄ کمیته راهبری، ثبت تصمیمات ADR، مدل محاسبه ROI          │
│  ۰۷. پیوست‌ها و سوابق معماری ◄ واژه‌نامه تخصصی دوزبانه، اسناد ADR-001 تا ADR-006      │
└────────────────────────────────────────────────────────────────────────────────────────┘
```
