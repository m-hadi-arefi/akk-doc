# فهرست سوابق تصمیمات معماری سیستم‌ها (ADRs Index)

## خلاصه مدیریتی
اسناد سوابق تصمیمات معماری (ADR) انتخاب‌های کلیدی مهندسی، زمینه تجاری آنها، گزینه‌های بررسی‌شده و پیامدهای بلندمدت را ثبت و مدون می‌سازند. این فهرست مجموعه ۶ تصمیم بنیادین معماری را که مبنای ساخت و توسعه سکوی مرکزی شرکت آرین خودرو قرار گرفته‌اند، مستند می‌کند.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              سوابق ۶ گانه تصمیمات بنیادین معماری                       │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  سند ADR-001 ◄ انتخاب معماری مونولیت ماژولار در برابر میکروسرویس‌های زودرس             │
│  سند ADR-002 ◄ استقرار لایه ضدفساد (ACL) برای همزیستی ایمن با سیستم تدارک دلفی         │
│  سند ADR-003 ◄ انتخاب پایگاه داده رابطه‌ای PostgreSQL 16 به عنوان هسته اصلی داده‌ها    │
│  سند ADR-004 ◄ معماری هاب داده‌های مرجع و رکورد طلایی شماره شاسی خودرو (VIN)           │
│  سند ADR-005 ◄ خط لوله ترکیبی استخراج اسناد (OCR) با نظارت اجباری کارشناس انسانی      │
│  سند ADR-006 ◄ ایجاد تیم مهندسی چابک داخلی در برابر برون‌سپاری کامل به شرکت‌های نرم‌افزاری│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## نتیجه‌گیری و گیت تصمیم‌گیری
- **تصمیم‌های کلیدی:** تصویب اسناد ADR شماره ۰۰۱ تا ۰۰۶ به عنوان قانون اساسی فنی توسعه سکوی مرکزی.
- **پرسش‌های باز:** تدوین سند ADR-007 جهت انتخاب ابزارهای جمع‌آوری لاگ‌ها و تله‌متری سیستم.
- **اقدام‌های بعدی:** مطالعه سند [ADR-001 مونولیت ماژولار](./adr-001-modular-monolith) جهت بررسی دلایل فنی انتخاب.
