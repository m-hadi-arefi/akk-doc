# اجرا، تحویل چابک و مدیریت تغییر سازمانی (Execution & Delivery)

## خلاصه مدیریتی
برترین استراتژی‌های تحول سازمانی اگر با انضباط عملیاتی اجرا نشوند، کاغذی بی‌ارزش خواهند بود. این بخش موتور محرکه اجرایی شرکت آرین خودرو را تدوین می‌کند: تواتر اسپرینت‌های دوهفته‌ای دومسیره (Dual-Track Agile)، پروژه‌های پایلوت با دستاوردهای سریع، چارچوب مدیریت تغییر سازمانی بر پایه مدل بین‌المللی ADKAR، و ماتریس جامع مدیریت و مهار ریسک‌های سازمان.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                موتور اجرایی و تحویل چابک سازمان                        │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  • تواتر چابک       ◄ اسپرینت‌های ۲ هفته‌ای؛ مدل دومسیره (شناخت مداوم + تحویل نرم‌افزار)│
│  • دستاوردهای سریع  ◄ پایلوت ۱: استخراج اسناد گمرک؛ پایلوت ۲: بارکد اسکن شاسی در انبار  │
│  • متدولوژی تغییر   ◄ مدل استاندارد ADKAR؛ طراحی مشترک، همدلی و شبکه مروجان داخلی      │
│  • حاکمیت ریسک      ◄ رجیستری ممیزی‌شده ریسک‌های فنی، فرهنگی، حقوقی و عملیاتی          │
│  • گیت‌های ارزیابی   ◄ اعمال دقیق تعریف «آماده» (DoR) و «انجام‌شده» (DoD) قبل از انتشار│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## نتیجه‌گیری و گیت تصمیم‌گیری
- **تصمیم‌های کلیدی:** تصویب چرخه اسپرینت‌های دوهفته‌ای دومسیره؛ انتخاب مدل سازمانی ADKAR برای مدیریت تغییر پرسنل.
- **پرسش‌های باز:** هماهنگی ورود فیزیکی تیم نرم‌افزار به محوطه انبار خودروها جهت اجرای پایلوت دوم.
- **اقدام‌های بعدی:** مطالعه سند [تحویل چابک و ریتم اسپرینت‌ها](./sprint-rhythm) جهت بررسی زمان‌بندی مراسم چابک.
