# ۲۵ — دفتر کل بدهی‌های فنی (Technical Debt Ledger)

## شناسنامه بدهی‌های فنی سازمان و اولویت‌بندی تسویه
بدهی فنی (Technical Debt) حاصل تصمیمات مهندسی شتاب‌زده یا به تعویق افتاده‌ای است که روزانه هزینه‌های سنگین عملیاتی، کندی سیستم و ریسک توقف کسب‌وکار را به شرکت تحمیل می‌کند. این دفتر کل، بدهی‌های فنی آرین خودرو را مستند و اولویت‌بندی می‌نماید.

## استراتژی توالی تسویه بدهی‌های فنی:
۱. **اقدامات فوری و بدون هزینه (روزهای اول تا سوم):** قطع پرینترها از یوپی‌اس (TD-01)، ایزوله کردن یک نسخه بک‌آپ آفلاین (TD-06) و تغییر رمزهای اصلی در یک گاوصندوق امن (TD-09).
۲. **تثبیت زیرساخت سخت‌افزاری (هفته‌های اول تا چهارم):** جایگزینی سرورهای سازمانی مجهز به رم ECC (TD-02) و شبکه وای‌فای صنعتی انبار (TD-10).
۳. **جداسازی معماری و رفع وابستگی‌ها (هفته‌های سوم تا هشتم):** ایجاد قراردادهای رسمی API پورتال (TD-04)، مرجعیت WMS برای موجودی با لایه ACL (TD-05) و اجرای پایلوت CRM (TD-07).
