# داکیومنت‌های وضعیت فعلی و مخزن مستندات عملیاتی

## خلاصه و هدف بخش
این بخش به عنوان مخزن رسمی، زنده و سازمان‌یافته برای ثبت، نگهداری و بارگذاری تمامی **مستندات وضعیت فعلی (Current State Documents)** شرکت آرین خودرو اختصاص یافته است. در حالی که بخش [داکیومنت‌های بررسی اولیه](/fa/initial-review/) دربرگیرنده معماری جامع تحول و نقشه راهبردی است، این فضا برای گردآوری مستندات فرآیندی جاری، شناسنامه سیستم‌های فعال، فهرست فایل‌های اکسل عملیاتی و دستورالعمل‌های کاری شعب و دپارتمان‌ها طراحی شده است.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                          ساختار مخزن مستندات وضعیت فعلی سازمان                         │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  ۱. فرآیندهای عملیاتی جاری  ◄ جریان‌های کاری فروش، ترخیص گمرکی، خدمات پس از فروش و انبار│
│  ۲. شناسنامه سیستم‌ها       ◄ نرم‌افزار قدیمی تدارک، سامانه رهبران، نرم‌افزارهای کمکی   │
│  ۳. رجیستری اکسل‌های جاری   ◄ فایل‌های محاسبه سود/زیان، رهگیری شاسی‌ها، کاردکس‌های انبار │
│  ۴. فرم‌ها و چک‌لیست‌ها      ◄ فرم‌های بازرسی PDI، صورتجلسات تحویل خودرو، چک‌لیست‌های گمرک│
│  ۵. رویه‌ها و دستورالعمل‌ها  ◄ آئین‌نامه‌های داخلی، شرح وظایف پرسنل و شیوه‌نامه‌های اجرایی│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## وضعیت مخزن: آماده برای ثبت و بارگذاری مستندات
> 📌 **وضعیت: آماده دریافت مستندات جدید**  
> این بخش به گونه‌ای معماری شده که تیم‌ها، مدیران میانی و کارشناسان بتوانند مستندات وضع موجود واحد خود را در آن مستقر نمایند.

جهت آشنایی با فرآیند استاندارد افزودن مستند به این بخش، [راهنمای ایجاد مستندات جدید](./guide) را مطالعه فرمایید.

---

## دسته‌بندی‌های مصوب جهت بارگذاری مستندات

| دسته‌بندی | شرح و قلمرو محتوا | قالب استاندارد |
| :--- | :--- | :--- |
| **فرآیندهای عملیاتی** | تشریح گام‌به‌گام فرآیندهای خرید خارجی، لجستیک، ترخیص، انبارداری، PDI و فروش. | متون مارک‌داون + دیاگرام فرآیندی |
| **شناسنامه سیستم‌ها** | فهرست نرم‌افزارهای فعال شرکت، نسخه‌ها، پایگاه‌های داده و ارتباطات فنی. | جداول شناسنامه نرم‌افزار |
| **فهرست اکسل‌های عملیاتی** | اطلاعات فایل‌های اکسل در گردش در واحدهای مالی، بازرگانی، مهندسی و فروش. | رجیستری اکسل‌ها با ذکر متولی |
| **دستورالعمل‌ها و SOPها** | شیوه‌نامه‌های مصوب تحویل خودرو، کنترل کیفی، عیب‌یابی و پشتیبانی مشتریان. | قالب استاندارد رویه‌ها |
