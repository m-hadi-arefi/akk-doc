# واژه‌نامه تخصصی اصطلاحات مهندسی آریان خودرو

| اصطلاح | تعریف تخصصی |
|---|---|
| **ACL** | لایه ضدفساد (Anti-Corruption Layer) — آداپتوری که سیستم مدرن را از پیچیدگی‌های سیستم‌های قدیمی ایزوله می‌کند. |
| **ADR** | سوابق تصمیم‌گیری معماری (Architecture Decision Record) — سندی تغییرناپذیر که تصمیمات معماری را ثبت می‌کند. |
| **ARB** | کمیته حاکمیت معماری (Architecture Review Board) — مرجع رسمی تصویب و بازبینی تصمیمات فنی در سازمان. |
| **BABOK** | پیکره دانش تحلیل کسب‌وکار — استاندارد معتبر بین‌المللی برای فرآیندهای تحلیل کسب‌وکار. |
| **BPMN** | مدل و نشانه‌گذاری فرآیندهای کسب‌وکار — استاندارد بصری برای رسم و مدل‌سازی گردش‌کارهای سازمان. |
| **CDC** | دریافت تغییرات داده‌ها (Change Data Capture) — استخراج و استریم بلادرنگ تغییرات دیتابیس در بستر رویدادها. |
| **Core Platform** | سکوی قابلیت‌های مشترک سازمان نظیر هویت، پیام‌رسانی، لاگ و درگاه‌ها (مستقل از منطق تجاری ERP). |
| **CQRS** | جداسازی مسئولیت فرمان و پرس‌وجو — تفکیک مدل‌های نوشتن و خواندن برای افزایش مقیاس‌پذیری. |
| **MDM** | مدیریت داده‌های مرجع (Master Data Management) — منبع واحد حقیقت برای موجودیت‌های اصلی سازمان نظیر مشتری و خودرو. |
| **Saga** | الگوی مدیریت تراکنش‌های توزیع‌شده از طریق توالی رویدادها و تراکنش‌های جبران‌ساز. |
| **Strangler Fig** | الگوی مهاجرت تدریجی که سرویس‌های موروثی را گام‌به‌گام با سرویس‌های جدید جایگزین می‌کند. |
| **Tadark** | نرم‌افزار قدیمی حسابداری و انبار قطعات شرکت آریان خودرو (توسعه‌یافته با دلفی ۳۲ بیتی). |
| **TOGAF** | چارچوب باز معماری گروهی — استاندارد جامع تدوین معماری سازمانی. |
| **VIN** | شماره شناسایی ۱۷ رقمی و منحصربه‌فرد هر خودرو (Vehicle Identification Number). |
