# ستون پایگاه دانش

**پایگاه دانش مهندسی** مرجع مرکزی شرکت آریان خودرو برای اصول مهندسی نرم‌افزار، الگوهای اثبات‌شده معماری، استانداردهای بین‌المللی، قالب‌های قابل استفاده مجدد و چارچوب‌های تصمیم‌گیری فنی است.

## فهرست بخش‌های پایگاه دانش

| بخش | شرح محتوا |
|---|---|
| [شناخت شرکت و سازمان](./company/overview.md) | دامنه‌های تجاری، ساختار شرکت، سوابق صنعتی و اصطلاحات خاص آریان خودرو. |
| [مفاهیم و نظریه‌های معماری](./architecture/overview.md) | مفاهیم بنیادین سیستم‌های توزیع‌شده و تئوری‌های معماری نرم‌افزار (CAP, CQRS, Saga). |
| [کاتالوگ الگوها](./patterns/overview.md) | الگوهای استانداردسازی‌شده در معماری، یکپارچه‌سازی، تاب‌آوری و مدیریت داده‌ها. |
| [کاتالوگ استانداردها](./standards/overview.md) | استانداردهای مرجع بین‌المللی مورد پذیرش (BABOK, TOGAF, ISO 42010, BPMN). |
| [برنامه‌نویسی و کد تمیز](./programming/overview.md) | استانداردهای مهندسی، اصول پنج‌گانه SOLID و قواعد بازبینی کد. |

| [چارچوب‌های تصمیم‌گیری](./decision-frameworks/overview.md) | مدل‌های مدون تحلیل موازنه‌ها (ساخت در مقابل خرید، مونولیت در برابر میکروسرویس، همگام در برابر ناهمگام). |
| [هوش مصنوعی در مهندسی نرم‌افزار](./ai/overview.md) | راهنماهای مهندسی پرامپت، دستیارهای کدنویسی AI، ابزارهای MCP و حاکمیت نظارت انسانی. |
