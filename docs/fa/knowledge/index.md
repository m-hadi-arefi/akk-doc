# پایگاه دانش مهندسی و الگوهای معماری

این بخش کلیه مباحث تئوریک، استانداردهای بین‌المللی مهندسی نرم‌افزار، الگوهای طراحی و چارچوب‌های مدیریت پروژه را که به عنوان پشتوانه علمی سکوی مرکزی و نقشه راه آرین خودرو استفاده می‌شوند گردآوری کرده است. با تفکیک این مباحث، مسیرهای اجرایی عملیات شفاف و متمرکز باقی می‌مانند.
