# مهندسی نرم‌افزار ارتقایافته با هوش مصنوعی

## مرور کلی
اصول استفاده از هوش مصنوعی برای شتاب‌بخشی به چرخه تحویل نرم‌افزار، همراه با تضمین کیفیت مهندسی و حفظ امنیت داده‌های سازمانی.

## اصول و روش‌های کلیدی

### ۱. مهندسی پرامپت برای توسعه‌دهندگان
- **تزریق زمینه معماری (Context Injection)**: ارائه صریح محدودیت‌های معماری، اینترفیس‌ها و انتظارات مدیریت خطا در دستور ارسالی به مدل.
- **نمونه‌های مرجع (Few-Shot)**: ارائه چند نمونه از کدهای استاندارد پروژه پیش از درخواست پیاده‌سازی ماژول‌های جدید.
- **تست‌محوری**: همواره از مدل خواسته شود که کدهای تست واحد متناظر را همراه با منطق اصلی تولید کند.

### ۲. پروتکل کانتکست مدل (Model Context Protocol - MCP)
- استفاده از ابزارهای استاندارد MCP برای اتصال امن دستیارهای هوش مصنوعی به مستندات، پایگاه‌های داده و ابزارهای مهندسی بدون افشای کلیدها و اسرار سیستم.

### ۳. اصل نظارت و حاکمیت انسانی (Human-in-the-Loop)
```text
پیشنهاد هوش مصنوعی ──► بررسی انسان ──► اجرای تست‌های خودکار CI ──► تأیید و ادغام انسان
```
- هیچ کدی که با هوش مصنوعی تولید شده باشد اجازه ورود مستقیم به شاخه‌های اصلی را بدون بازبینی انسانی و قبولی در تست‌ها نخواهد داشت.
