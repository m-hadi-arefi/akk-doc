# Diagrams

Architecture diagrams and visual assets for the Arian Khodro project.

## Conventions

- All diagrams should be source-managed (preferably in a diagram-as-code format).
- Diagrams should be referenced from their relevant documentation sections.
- Diagrams should be simple and clear — avoid unnecessary detail.

## Diagram Tools

Consider using:

- **Mermaid** — Diagrams defined in Markdown (renders natively in many Markdown viewers)
- **PlantUML** — UML diagrams from text descriptions
- **Draw.io / diagrams.net** — Browser-based diagramming with XML source
- **Excalidraw** — Hand-drawn style diagrams

## Guidelines

- Every diagram should have a caption and a description of what it shows.
- Every diagram should have a source file and a rendered version.
- Diagrams should be updated when the architecture changes.
- Diagrams should not contain confidential or sensitive information.
